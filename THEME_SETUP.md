# LUXORA Theme Setup Guide

## العربية

كل محتوى المتجر قابل للتعديل من لوحة زد أو محرر الثيم، ولا توجد بيانات خاصة بمتجر LUXORA مفروضة على المشتري.

### الأسئلة الشائعة

- أضف أسئلة المتجر من لوحة زد إن كانت ميزة الأسئلة الشائعة متاحة في باقتك.
- عند عدم وجود أسئلة في زد، يعرض الثيم أربع أسئلة افتراضية يمكن تعديلها من: إعدادات الثيم ← الأسئلة الشائعة الافتراضية.
- أسئلة زد لها الأولوية تلقائيًا على الأسئلة الافتراضية.

### صفحات من نحن والإرجاع والتواصل

1. أنشئ الصفحات من لوحة زد ← المتجر الإلكتروني ← الصفحات.
2. أدخل النص والصور الخاصة بعلامتك التجارية.
3. انسخ رابط كل صفحة إلى إعدادات الثيم ← Footer ← روابط الصفحات.
4. الرابط الفارغ لا يظهر للزوار ولا ينتج صفحة 404.

### روابط التواصل الاجتماعي

أدخل روابط Instagram وTikTok وSnapchat وX ورقم WhatsApp من إعدادات Footer. أي منصة بلا رابط تُخفى تلقائيًا.

### المنتجات متعددة الصور والمقاسات والألوان

1. أضف صور المنتج من إدارة المنتجات في زد؛ يدعم الثيم المعرض والتنقل والفتح بالحجم الكامل تلقائيًا.
2. أضف خيارات مثل اللون والمقاس من خيارات المنتج.
3. اربط السعر والمخزون بكل SKU/خيار من لوحة زد.
4. أضف وصف المنتج ودليل المقاسات والحقول المخصصة عند الحاجة.

## English

All store content is editable from Zid Dashboard or the theme editor. No LUXORA-specific merchant data is forced on buyers.

### FAQs

- Add merchant FAQs from Zid Dashboard when the feature is available on the store plan.
- When Zid has no FAQs, the theme shows four editable defaults under Theme Settings → Default FAQs.
- Zid-managed FAQs automatically take priority.

### About, Returns, and Contact pages

1. Create pages in Zid Dashboard → Online Store → Pages.
2. Add the merchant's own copy and images.
3. Paste each page URL into Theme Settings → Footer → Page Links.
4. Empty links remain hidden and never create broken navigation.

### Social links

Enter Instagram, TikTok, Snapchat, X, and WhatsApp under Footer settings. Platforms without a URL are hidden automatically.

### Products with multiple images, sizes, and colours

1. Upload product media in Zid Products; the theme automatically enables gallery navigation and full-size viewing.
2. Add colour and size options through product options.
3. Assign price and inventory to each SKU/combination.
4. Add product descriptions, size information, and custom fields as needed.
